# Remotes
Folder ini berisi definisi RemoteEvent / RemoteFunction, dikelompokkan per sistem
(subfolder per domain, mis. `Combat/`, `Inventory/`, `Quest/`, `Gate/`).

Setiap Remote baru WAJIB:
1. Didaftarkan di tabel referensi "Remote Events / Functions" pada `docs/02_TDD.md`.
2. Punya validasi server (lihat `docs/06_CODING_STANDARDS.md` §3 — checklist anti-exploit)
   sebelum ditandai selesai di `docs/05_PROGRESS_TRACKER.md`.

Belum ada Remote yang dibuat — folder ini masih skeleton kosong.
